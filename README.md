# Manufacturing Quality Analytics Dashboard

## Project Overview

This project is an end-to-end Manufacturing Quality Analytics solution developed to analyze machine performance, identify quality issues, and provide actionable insights using data analytics techniques.

The project demonstrates the complete data analytics workflow—from data cleaning and SQL analysis to interactive Tableau dashboard development and business storytelling.

---

## Business Problem

Manufacturing organizations need to monitor machine performance to reduce failures, improve product quality, and minimize downtime.

The objective of this project is to:

- Analyze machine failure patterns
- Identify factors influencing machine failures
- Monitor production by product type
- Provide data-driven recommendations for preventive maintenance

---

## Project Objectives

- Clean and preprocess manufacturing quality data
- Perform Exploratory Data Analysis (EDA)
- Write SQL queries to answer business questions
- Build an interactive Tableau dashboard
- Generate business insights and recommendations
- Showcase an end-to-end Data Analyst portfolio project

---

## Dataset

**Dataset:** AI4I 2020 Predictive Maintenance Dataset

The dataset contains information about:

- Product Type
- Air Temperature
- Process Temperature
- Rotational Speed
- Torque
- Tool Wear
- Machine Failure

Total Records: **10,000**

## Key Business Insights

- Overall machine failure rate is **3.39%**.
- L-type products recorded the highest failure rate.
- Machines with higher tool wear experienced significantly more failures.
- Preventive maintenance based on tool wear can reduce unexpected machine failures.
